# 各模块审查结果

审查更新：2026-10-18。对象为 0.35.1 独立发行候选。源码仍在本地，本页仅记录模块职责、已验证范围与限制。

## 来源与实现

维护者已确认自研部分由其委托 GLM 编写，庄园模块完全由其委托 GLM 编写。对六个公开 Companion 插件的具体版本未发现换壳或主要实现直接复用；详细比较范围与方法见 [结构审查](SOURCE_REVIEW.md)。此来源确认已纳入正常发行审查，不再以缺少庄园初代存档单独阻断。

## 性能与安全边界

- 环境上下文默认预算为 420 **字符**，不是精确 token 上限。预算、去重和重试已有断言；未执行真实计费比较。
- 慢天气文件读取已移出事件循环，保留原观测时间；不把“读取一次文件”当成新天气。
- 缓存使用有界摘要和必要状态，卸载清理任务/引用；不会声称能强制终止已经进入操作系统调用的线程或不合作的第三方任务。
- API 是受信插件之间的契约，不是恶意插件沙箱，不承诺任意跨线程写入安全。
- 发行候选不含真实账号、聊天、日志、数据库、私服配置和原开发历史；后端继续使用官方页面鉴权链，不带私人 Token 分支。
- 可选 3D CDN/WebGL 的完整网络与渲染兼容没有实测；2D 页面验证不能代替它。

## 测试口径

采用同哈希版本已执行的 782 项 Python、12 项 Node、54 项官方 AstrBot SDK 检查及五页 Chromium 验收记录；本轮重算文件哈希并做静态解析，没有把旧执行说成新运行。详见 [发行状态](RELEASE_STATUS.md)。

当前没有新的技术、安全或已识别未经授权复用问题阻止形成安装候选。维护者选择保留非商业限制、先发审查文档，因此这些技术结果不被写成插件源码已公开发行。
