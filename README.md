## 插件定位

候选以身体、接触、空间、材质和心绪状态为基础，通过可选的统一状态接口接收音乐、天气、设备、时间等环境信息，按有效期、会话范围和上下文预算筛选后，向原有 LLM 请求添加临时上下文。

```text
消息事件 / 感知状态提供者
          ↓
身体与空间状态 / Presence 状态管理
          ↓
有效期、范围、去重与预算筛选
          ↓
临时上下文 → AstrBot 原有 LLM 调用
```

它不自行采集全部手机或天气数据，也不替换宿主的人格提示词、聊天系统或记忆数据库。外部状态提供者缺失时保留未知状态。

## 本轮结论

- 与 menglimi 六个相关公开插件的工程结构、业务模型和主要调用链不同；在所查固定版本中，未发现整体换名套壳或直接复用主要实现的证据。
- `Star`、生命周期、配置文件和 Pages 接口是共同宿主规范，不能单独作为套用代码的依据。
- 当前候选沿用旧版虚拟存在层及曾并入的空间模块，不能将本轮整理称为从零原创。维护者对委托创作来源的确认已纳入审查，不再以缺少初代源码单独阻断发布。
- 技术和敏感信息审核通过不等于版权、许可证及公开发布条件全部通过。
